# 🚀 CryptoVision AI

A premium cryptocurrency analytics dashboard built using Python and Streamlit.

## Features

- 📊 Multi-Coin Dashboard
- 📈 Compare 3 Cryptocurrencies
- 📉 Forecasting with Prophet
- ⚡ RSI / MACD / Bollinger Bands
- 📊 Correlation Analysis
- 💼 Portfolio Simulator
- 🎨 Premium Fintech UI

## Tech Stack

- Python
- Streamlit
- Plotly
- Pandas
- Prophet
- Scikit-learn
